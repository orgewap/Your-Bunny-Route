ОБНОВЛЕНИЕ: статусы импортированных, новых и изменённых дорог

Работает с road-editor-starter.zip (последний присланный проект),
поверх уже установленного traffic-lane-signs-update.zip.

Цветные контуры по обоим краям каждой дороги:
  синий     — импортирована из открытого OSM и пока не изменялась;
  зелёный   — новая OSM-дорога, созданная в текущем проекте;
  оранжевый — изменена после импорта (геометрия, узлы, полосы, теги).
В 3D тонкие контуры нарисованы на кромках полотна.
Режимы и экспорт OSM не изменены. Легенда отображается постоянно.

УСТАНОВКА В CMD (из корня road-editor-starter):
  tar -xf "%USERPROFILE%\Downloads\road-status-outlines-update.zip" -C .
  npm run typecheck
  npm run test:topology
  npm run dev

АЛЬТЕРНАТИВА: Git-патч (только если файлы соответствуют версии выше):
  git apply --check "%USERPROFILE%\Downloads\road-status-outlines.patch"
  git apply "%USERPROFILE%\Downloads\road-status-outlines.patch"

Перед любым вариантом сделайте резервную копию проекта.
Патч и ZIP содержат один и тот же исходный код — НЕ применять их оба.

Статусы отсчитываются от последнего загруженного OSM. Если заново импортировать
edited.osm, это становится новым исходным файлом и все его дороги считаются
«импортированными» до следующего редактирования. Статусы не записываются в OSM.
