ОБНОВЛЕНИЕ: Значки / стоп-линии / выбор полос
============================================
Основано на присланном road-editor-starter.zip (10.11.2026).

Установка:
1. Сделайте резервную копию папки проекта.
2. Скопируйте traffic-lane-signs-update.zip в Загрузки.
3. В CMD в корне road-editor-starter:
   tar -xf "%USERPROFILE%\Downloads\traffic-lane-signs-update.zip" -C .
   npm run typecheck
   npm run test:topology
   npm run dev

Проверка: 137/137 тестов, vue-tsc без ошибок.
Сборка vite build в проверочной Linux-среде не запускалась успешно:
архив содержит Windows node_modules без Linux-native Rollup.
На Windows дополнительно запустите npm run build.

Использование:
- V -> клик по пиктограмме знака -> справа выбор дороги, направления и полос.
- Для дороги из 5 полос можно отметить только 2 и 3.
- Светофор / STOP имеют автоматическую визуальную стоп-линию.
- Инструмент «Стоп-линия» создаёт настоящую OSM-линию по отмеченным полосам.
- Для нескольких не соседних групп полос создайте отдельные физические линии.

Важно: служебные теги road_editor:lanes и road_editor:road в edited.osm
нужны для последующего открытия проекта в редакторе. Сами SUMO/Webots
не обязаны интерпретировать их как правила движения.
