Исправление работы с несколькими OSM и участниками
=================================================

Устанавливать ТОЛЬКО поверх текущей версии road-editor-starter, из которой
был получен ZIP в этом разговоре. Архив содержит исключительно исходный код,
НЕ содержит backend/data, SQLite, паролей или файлов проектов.

Исправлено:
- Поддержка WebSocket в зависимостях Python (uvicorn[standard]).
- Удаление источника OSM с сохранением зависимых дорог/узлов и маршрутов.
  Если другой OSM-объект ссылается на дорогу удаляемого источника, дорога
  сохраняется и показывается уведомление о количестве таких объектов.
- Отчёт наложений теперь показывает одинаковые положительные OSM ID,
  даже если геометрия и теги полностью совпадают.
- Оповещение участников при удалении серверного проекта.

Windows CMD, из корня проекта:
  python -m pip install -r backend\requirements.txt
  python -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
В другом терминале:
  npm run typecheck
  npm run test:topology
  npm run dev

Перед заменой файлов сохраните полную копию проекта, особенно backend/data.
Не копируйте backend/data из OLD-архива: там другая ревизия проекта.

Проверки на копии предоставленных данных:
  backend: 48 тестов OK
  TypeScript: vue-tsc --noEmit OK
  frontend: 176 тестов OK
  remove edited.osm: сохранены 44 дороги и 314 узлов, связанных с
  остающимися маршрутами; новых повреждённых ссылок не создано.

Оговорка: исходные OSM-отношения могут ссылаться на элементы, которые не
входят в географическую выгрузку. Это было до обновления, удаление
источников не должно создавать дополнительных таких ссылок.
