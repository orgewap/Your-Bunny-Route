ЭТАП 1 — ГЕОМЕТРИЯ ДОРОГ, ТОЧКИ, СОЕДИНЕНИЯ И TAB

Обновление подготовлено на основе road-editor-fast-optimized-full.zip.
Внутри — весь рабочий проект, включая Windows node_modules.
Остальные функции и проектная архитектура не переписывались.

УСТАНОВКА
1. Распаковать road-editor-lines-stage1-full.zip в новую папку.
2. В CMD открыть папку road-editor-starter и выполнить:
   npm run typecheck
   npm run test:topology
   npm run dev
3. Если библиотека Rollup не запускается: npm ci и повторить.

РУЧНАЯ ПРОВЕРКА (НА ТВОЁМ OSM)
1. Открыть OSM. Выбрать старую дорогу и посмотреть белые редактируемые точки.
2. В режиме «Выбор» дважды щёлкнуть по её пунктирной оси (НЕ по существующей точке).
   Должна появиться новая контрольная точка. Зажать и передвинуть её.
3. Взять конец существующей дороги и перетащить на другую дорогу.
   Конец должен прикрепиться к ней общим OSM-узлом, а соседние улицы
   не должны перетаскиваться вслед за конечной точкой.
4. Нарисовать ответвление из пера от внешней полосы 4-полосной дороги.
   Сначала проверить в 2D, затем в 3D. Ранее импортированные улицы не
   должны внезапно обрезаться.
5. Навести курсор на карту, зажать Tab и перетащить дорогу.
   Работает и без предварительного выделения; отпускание Tab прекращает
   изменение положения даже до отпускания кнопки мыши.
6. Ctrl+Z / Ctrl+Y. Экспорт edited.osm. После повторного импорта проверить
   общие узлы и дорожную геометрию.

ИЗМЕНЕНИЯ
- Правило скрытия короткого отрезка применяем только к явно созданному
  переходу от полосы к общему узлу, но не к произвольным исходным OSM-дорогам.
- При выборе дороги отображается её настоящая ось и контрольные точки.
- Выбор и Tab распознают визуальную ширину полос вместо одной осевой линии.
- Перетаскивание отдельной общей точки больше не сдвигает всю соседнюю сеть.
- После attach/detach редактор обновляет геометрию через geometryRevision.
- Вставка точки двойным кликом по оси выбранной дороги в 2D.

ГРАНИЦЫ ЭТАПА
- В этом обновлении не добавлены backend, проекты, одновременный импорт
  нескольких OSM, светофоры, стоп-линии и новые инструменты перекрёстков.
- Точные переходы lane-to-lane для SUMO/Webots/MATSim пока не реализованы.
- Сложные соединения у мостов нужно проверять дополнительно вручную в 3D.
