# Состояние реализации по техническому заданию

| Функция | Статус | Примечания |
|---|---|---|
| Загрузка локального OSM XML | Есть | Неизвестные объекты сохраняются в исходном XML |
| Подробная картографическая подложка | Есть | OpenFreeMap Liberty, нужен интернет |
| Создание прямых и кривых дорог | Есть | Два клика или три контрольные точки |
| Привязка к OSM-узлу | Есть | Присваивается исходный ID узла |
| Привязка к середине OSM way | Есть | В существующую дорогу добавляется новый общий узел |
| Поиск геометрических пересечений | Есть | Локальный алгоритм на метрических координатах |
| Мост над пересекаемой дорогой | Есть | Предлагается автоматически, отдельный новый OSM way `bridge=yes`, `layer=*` |
| Уровни мостов +1/+2 | Есть | +2 предлагается при пересечении над +1; выше +2 — ошибка |
| Выбор между мостом и перекрёстком | Есть | Выбор для каждого пересечения, подсветка на карте, подтверждение |
| Ложные соединения мостов | Исключены при создании | Мост не получает общий узел с дорогой под ним |
| Изменение свойств и удаление участка | Есть | Локально, Undo/Redo |
| 2D и схематичный 3D | Частично | MapLibre fill-extrusion; Three.js и реалистичные подъезды отсутствуют |
| Плавные уклоны, опоры, точная геометрия мостов | Нет | Требует дополнительного моделирования |
| Соединения отдельных полос и turn restrictions | Нет | Пока только `lanes` и `oneway` |
| Конвертация MATSim / SUMO / Webots | Нет | Нужен отдельный сервис команды |
| Проверка связности / relations перед экспортом | Частично | При создании сохраняется локальный граф, но полная серверная валидация отсутствует |
| Docker Compose | Нет | Пока фронтенд запускается через Vite |

Это рабочий функциональный редактор для локального OSM, но не полный MVP по всем пунктам ТЗ.
