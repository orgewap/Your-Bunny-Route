# Дорожная инфраструктура — в редакторе и OSM

Это обновление заменяет отдельные команды **Webots 3D** и **+ .wbt** на отрисовку инфраструктуры в уже существующем 3D-режиме MapLibre.

- Выберите автомобильную дорогу → справа **Инфраструктура 3D**.
- Бордюры: автоматически из `sidewalk=left/right/both` либо вручную по сторонам и высоте.
- Ограждения: выбор левой/правой стороны. Отдельные импортированные OSM-линии `barrier=kerb`, `barrier=guard_rail`, `barrier=wall` также показываются.
- Опоры: на повышенных мостах с настраиваемым шагом; попытки поставить опору внутри другой наземной дороги исключаются.
- Светофоры и знаки STOP/YIELD: упрощённые 3D-стойки, без выдуманного цикла фаз.
- Разметка: окрашенные 3D-полосы и стоп-линии поверх дорожного покрытия. Зебры — только там, где они отмечены в OSM.
- Для просмотра выберите **3D**, приблизьте карту до уровня 14+ для объектов инфраструктуры, 15+ для дорожной разметки.

## Сохранение

Обычная кнопка **Экспорт OSM** сохраняет все существующие OSM-теги и локальные `road_editor:kerb`, `road_editor:kerb_height`, `road_editor:guard_rail`, `road_editor:bridge_support`, `road_editor:support_spacing`. Сами 3D-полигоны не являются дополнительными OSM ways; это визуализация по данным OSM. Исходная геометрия дорог и связность OSM не меняются.

Для Webots важно различать **параметры** в OSM и **полноценную 3D-геометрию `.wbt`**. Стандартный OSM Importer Webots не обязан понимать пользовательские `road_editor:*` теги; Webots-конвертеру по-прежнему нужен отдельный адаптер для создания физических бордюров и опор. Внешние файлы Webots не создаются и не скачиваются при обычном экспорте OSM.

Инструменты проектов, пользователей, совместной работы, пешеходных графов, мостов и дорожной геометрии остались без изменений.
