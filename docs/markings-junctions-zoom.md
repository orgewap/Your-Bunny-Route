# Исправление 2D-разметки и масштабирования

Обновление **не меняет исходную OSM-топологию и экспорт**. Это только корректное построение слоёв MapLibre.

- `crosswalks.ts`: полосы «зебры» — метрические прямоугольники (`Polygon`), длинной стороной вдоль движения автомобилей, расположенные поперёк всей ширины дороги. Геометрия масштабируется вместе с картой. Разметка показывается только при явно указанных `crossing:markings` или `crossing=zebra/marked`; произвольный `crossing=traffic_signals` не превращается в выдуманную «зебру».
- `junctionMarkings.ts`: по общим OSM-узлам определяется реальный перекрёсток с тремя и более дорожными направлениями. Разделительная разметка, тёмные границы полос и цветные контуры статуса дорог обрезаются у его границ. Два продолжающих друг друга отрезка не маскируются как перекрёсток; мост над обычной дорогой на другом уровне не получает ложного соединения.
- `mapScale.ts` и `MapEditor.vue`: метрические ширины/отступы теперь продолжают масштабироваться вплоть до zoom 24 (прежний набор stop'ов заканчивался на zoom 20). Пешеходные дорожки и стоп-линии также меняют экранную толщину при приближении, сохраняя минимальную удобную толщину на дальнем масштабе.

## Установка

Сделайте резервную копию текущего проекта. Установите ZIP поверх последней версии с пешеходным графом **либо** примените `.patch`; оба способа одновременно не используются.

```cmd
cd /d "C:\Users\muhmr\OneDrive\Desktop\road-editor-starter"
tar -xf "%USERPROFILE%\Downloads\crosswalk-junction-zoom-fix.zip" -C .
npm run typecheck
npm run test:topology
npm run build
npm run dev
```

В браузере обновите страницу с очисткой кеша (`Ctrl+F5`). Проверьте четырёхсторонний перекрёсток при zoom 18, 20 и 22. Линии между полосами должны обрываться перед пересечением, а «зебра» — быть ориентирована вдоль дороги.

Ограничение: если в исходном OSM дороги геометрически пересекаются, но не имеют общего узла, редактор не считает это перекрёстком. Пешеходная разметка без явных тегов в данном обновлении не угадывается.
