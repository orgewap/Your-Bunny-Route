# Анализ дорожной сети — первая версия

## Назначение

Панель «Анализ» проверяет связность автомобильного графа и ранжирует найденные проблемы. Результаты являются временными данными интерфейса: они не добавляют OSM-теги, не меняют геометрию и не попадают в экспорт или серверное сохранение проекта.

## Проверки

- **Изолированная дорога** — новый или изменённый автомобильный участок не имеет общих узлов с другими дорогами; критическая ошибка. Изолированная импортированная дорога — предупреждение, если её теги не указывают на намеренный частный подъезд.
- **Изолированное кольцо** — замкнутая дорога или круговой перекрёсток не имеет внешних подключений; критическая ошибка для созданного/изменённого объекта и предупреждение для неизменённого импорта.
- **Отдельный фрагмент сети** — несколько связанных между собой дорог не подключены к основной компоненте; критическая ошибка для нового/изменённого фрагмента, предупреждение для импортированного. Явно частные подъезды остаются информационными замечаниями.
- **Неподключённый конец** — у созданной/изменённой дороги, уже связанной с сетью, остаётся один или два свободных конца; предупреждение. Для `noexit=yes`, `service=driveway` и `access=private` это информационное замечание.
- Изолированные импортированные участки отображаются как предупреждения, кроме явно частных/служебных подъездов. Свободные концы внутри основной сети не считаются ошибкой только из-за границы OSM-выгрузки.

## Правила топологии

1. Две дороги соединены, если имеют общий ID узла и одинаковый `level`.
2. Простое пересечение координат не создаёт соединение.
3. Мост и дорога под ним на разных уровнях не считаются перекрёстком, даже если XY совпадает.
4. Пешеходные ways исключены из первой версии анализа; для них будет отдельный анализ в следующем этапе.
5. Дополнительная проверка ищет свободные концы в радиусе 4 м от сегментов другой дороги того же уровня. На карте отмечаются только свободный конец, ближайшая точка на целевой дороге и короткий разрыв между ними; геометрия и OSM-узлы автоматически не меняются.
6. Основная компонента выбирается по числу и длине неизменённых импортированных дорог. Если импортированных дорог нет — по общей длине компоненты.
7. Изменением топологии считается создание дороги, изменение её уровня, состава узлов или координат. Правка только названия, полос или других тегов не делает неизменённый участок критической топологической ошибкой.

## Критичность

- **Критическая** — новый/изменённый участок изолирован либо новый фрагмент отделён от основной импортированной сети.
- **Предупреждение** — импортированный фрагмент отделён от основной сети, у дороги найден вероятный пропуск соединения в пределах 4 м или у изменённой дороги есть свободный конец. Для свободных концов подсвечивается только проблемная точка, не вся дорога.
- **Информация** — намеренный частный подъезд/тупик или близкий конец у дороги с явными тегами частного доступа.

Цвета на карте: красный — критическая, оранжевый — предупреждение, фиолетовый — информация. Изолированные дороги и отдельные компоненты подсвечиваются линиями; неподключённые концы и возможные пропуски соединений — точками и короткой линией разрыва. Подсветка доступна в 2D и может быть выключена в панели.

## Производительность и актуальность

Анализ запускается по кнопке, а не при каждом открытии вкладки. Алгоритм строит индекс узлов и компоненты связности за один проход по дорожным вершинам. После изменения геометрии старые результаты помечаются устаревшими и подсветка выключается до повторного запуска. Список ограничен первыми 80 карточками с дозагрузкой, чтобы большие OSM не перегружали интерфейс.

## Ограничения первой версии

- Анализируется автомобильная сеть, не пешеходная.
- Геометрическая близость без общего OSM node ID не считается реальным подключением. Близкие свободные концы показываются отдельно как возможные пропущенные соединения; автоматическое соединение не выполняется.
- Свободный конец может быть намеренным тупиком; автоматическое соединение не выполняется.
- Пока нет автоматического исправления, подтверждения «это намеренный тупик» и блокировки экспорта. Это отдельный следующий этап.
