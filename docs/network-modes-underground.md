# Разделение сети и обозначение подземных пешеходных путей

## Исправление видимости

Режимы «Авто», «Пешеходы», «Обе сети» управляют **не только списком справа**, но и слоями MapLibre / 3D-мешем:

| Режим | Автомобильное полотно | Пешеходные пути | Фоновые линии дорог OpenFreeMap |
| --- | --- | --- | --- |
| Авто | Да | Нет | Обычная карта |
| Пешеходы | Нет | Да | Скрыты при загруженном OSM (фоновая дорога — не часть графа) |
| Обе сети | Да | Да | Обычная карта |

В режиме «Пешеходы» остаются здания, названия улиц, зелёные зоны и другие элементы подложки. Переключение спутника работает независимо. При возвращении к «Авто» или «Обе сети» исходные видимости слоёв Liberty восстанавливаются.

Дополнительные точки / линии инфраструктуры фильтруются по активному графу; изменения геометрии не требуются.

## Подземные переходы

В `edited.osm` существуют `highway=footway`/`steps` с `tunnel=yes`, `tunnel=building_passage` и `layer=-1`. Они отображаются:

- фиолетовым пунктиром — подземные дорожки;
- стрелкой вниз ↧ — вход/выход на концах тоннельных участков;
- обычной зелёной линией — надземные пешеходные связи;
- зелёным пунктиром — предположенные тротуары из `sidewalk=*`, не включённые в маршрутизацию.

Применяются исходные OSM ID. Обычные пересечения линий в плане по-прежнему не создают связь между уровнем 0 и тоннелем. Маршрут по тоннелю работает только по общим OSM-узлам. Тротуары 3D намеренно **не рисуются на высоте +0.16 м** для туннелей; физическое моделирование глубины и объёма тоннеля в текущий патч не входит.

При изменении подземного OSM-объекта отрицательный `layer` сохраняется в экспорте.

## Проверка в браузере

1. Импортировать `edited.osm`, приблизить к пешеходным дорожкам (zoom 14–18).
2. Выбрать «Авто»: зелёные пути редактора должны исчезнуть, дороги оставаться.
3. Выбрать «Пешеходы»: автомобильное полотно и собственные линии дорог Liberty должны исчезнуть; остаются реальные зелёные дорожки, фиолетовые тоннели и зебры.
4. Выбрать «Обе сети»: оба набора появляются одновременно.
5. Перейти в 3D: полотно дорог в режиме пешеходов скрыто; тоннели — условный пунктир, а не возвышенное покрытие.
6. Экспортировать изменённую пешеходную дорожку с `layer=-1` и проверить, что тег остался.

Тесты геометрии и TypeScript не заменяют ручную проверку отрисовки MapLibre в браузере.
