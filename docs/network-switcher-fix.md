# Исправление переключателя графов

Режимы «Авто / Пешеходы / Обе сети» теперь применяются одновременно к картографическим слоям, 3D и Vue-интерфейсу. Переключение вызывает обновление геометрических источников даже без движения карты. Кнопки имеют явное состояние `aria-pressed` и не пропускают клики на MapLibre. В обоих графах остаются доступными контрольные точки для редактирования.

- Авто: автомобильные полосы, маркировка, дорожные объекты; скрыт пешеходный граф.
- Пешеходы: зелёные дорожки, фиолетовые подземные пути, переходы; автомобильные линии редактора и фоновая геометрия дорог Liberty скрыты.
- Обе сети: автомобильные и пешеходные слои вместе.

Спутниковая подложка — реальная фотография, её дороги нельзя скрыть переключателем.

Если кнопки не становятся зелёными, сравните `src/stores/editor.ts` с версией в обновлении: метод `setNetworkMode` обязан возвращаться из setup-хранилища вместе с `networkMode`.

Перед распаковкой сделайте копию проекта. Не применяйте ZIP и `.patch` одновременно. После установки выполните `npm run typecheck`, `npm run test:topology`, `npm run dev` и обновите страницу Ctrl+F5.
