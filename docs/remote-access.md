# Защищённый доступ к Road Network Editor для пяти человек

Этот этап **не меняет редактор**: дороги, OSM, мосты, граф полос и инструменты работают как раньше. Разворачивается единственный FastAPI-сервер, который отдаёт готовый Vue-интерфейс, `/api/*` и WebSocket `/api/projects/{id}/live` с одного домена. **Порт 8000 остаётся локальным** (`127.0.0.1`).

## 1. Сохраните данные

Перед первым внешним запуском скопируйте папку `backend/data` в отдельное место. Не выкладывайте эту папку в интернет или GitHub. В ней хранятся проекты, сессии и хеши паролей.

## 2. Сборка и запуск (Windows CMD)

В корне проекта:

```cmd
npm ci
npm run build
py -m pip install -r backend\requirements.txt
scripts\start-remote.cmd edit.example.com
```

Замените `edit.example.com` своим реальным поддоменом на Cloudflare. `start-remote.cmd` проверит наличие `dist/index.html`, включит защищённые сессионные cookies и запустит один Uvicorn worker **только на `127.0.0.1:8000`**. Это окно CMD оставьте открытым.

Проверка на локальной машине: откройте `http://127.0.0.1:8000` — должна открыться карта, `/api/health` должен вернуть `{"ok":true}`. В режиме защищённых cookies авторизовываться через локальный HTTP не нужно: вход пользователей проверяется по внешнему HTTPS-адресу.

Внешним участникам **не нужно запускать `npm run dev`**. Vite — инструмент разработки и не предназначен для публикации проекта. Настройка Vite-прокси `/api` остаётся только для локальной разработки.

## 3. Сначала настройте Cloudflare Access

Нужен домен, подключённый к Cloudflare (или поддерживаемая DNS-конфигурация), и аккаунт Cloudflare Zero Trust. Без домена безопасную постоянную публичную ссылку в рамках этого сценария не создаём.

1. Откройте Cloudflare Zero Trust → **Access controls → Applications**.
2. Создайте **Self-hosted application** для полного `edit.example.com` (включая `/api` и WebSocket URL).
3. Сделайте политику **Allow** только для *конкретных пяти email-адресов* команды; не используйте Everyone или Login Methods → One-time PIN в качестве критерия Allow.
4. Выберите существующий IdP или вход по email-коду (One-time PIN) и разумную длительность сеанса.
5. Приложение должно оставаться **deny by default** для всех остальных пользователей.

Это внешний уровень допуска. Каждый участник затем отдельно входит под своим существующим логином Road Editor (`user1`, `user2` и т. д.). Права проекта продолжает определять FastAPI.

## 4. Создайте Cloudflare Tunnel

В Cloudflare Dashboard → **Networking → Tunnels** создайте туннель. Добавьте маршрут Published application для `edit.example.com` с **Service URL `http://127.0.0.1:8000`**. Туннель запускайте `cloudflared` на той же машине, где запущен FastAPI. Можно использовать команду запуска, которую выдаёт Cloudflare Dashboard, либо локальный файл конфигурации по образцу `scripts/cloudflared-ingress.example.yml`.

**Обязательно включите `Protect with Access` в настройках Tunnel**, чтобы `cloudflared` проверял токен Access и на стороне origin. Используйте уже созданное приложение Access. Не публикуйте отдельный маршрут на порт `5173`, а также не пробрасывайте ни порт `8000`, ни порт `5173` на роутере. Не отключайте Access для `/api` или WebSocket.

В Windows `cloudflared` можно установить отдельно с официальной страницы загрузки. Если он уже установлен, проверьте `cloudflared --version`. Секретные токены/файлы туннеля храните вне папки проекта и не присылайте в чат или коммиты.

## 5. Проверка двумя и пятью пользователями

- Участник с разрешённым email открывает `https://edit.example.com`. Сначала появляется Cloudflare Access, затем штатная авторизация Road Editor.
- Запрещённый email должен получить отказ **до** страницы редактора.
- Войдите с двух разных компьютеров. Откройте общий проект, проверьте индикатор «Онлайн: 2».
- Измените **разные** дороги: сохранение должно синхронизироваться. Попробуйте конфликт по **одной** дороге: 409 и защита от перезаписи должны сохраниться.
- Откройте пять участников и проверьте `wss://edit.example.com/api/projects/<project_id>/live` в сетевых инструментах браузера (WebSocket → `101 Switching Protocols`).
- Перезапустите FastAPI: после перезапуска проекты и OSM должны остаться в `backend/data`.

## Ограничения

- Это тестовый командный сервер на одном ноутбуке: при выключении ноутбука или потере интернета редактор по внешнему адресу перестанет работать.
- **Один** Uvicorn worker: WebSocket-комнаты и файловые блокировки пока внутри одного процесса.
- Система не гарантирует производительность при пяти одновременных пользователях без проверки на реальной сети.
- Cloudflare Tunnel не заменяет приложение Access, HTTPS и авторизацию Road Editor.
- Длительную эксплуатацию лучше переносить на VPS с резервными копиями, мониторингом, обновлениями безопасности и специализированным общим хранилищем.

Ссылки на официальные инструкции Cloudflare: https://developers.cloudflare.com/tunnel/get-started/ и https://developers.cloudflare.com/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/ .
