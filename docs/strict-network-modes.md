# Изоляция автомобильного и пешеходного графов

- «Авто»: только автомобильный граф, включая полосы и разметку; пешеходные источники MapLibre очищены.
- «Пешеходы»: только пешеходные связи, переходы и подземные участки; автомобильные источники очищены, 3D-меш автомобиля выключен.
- «Обе сети»: оба графа.

Почему раньше выбор выглядел бесполезным: OpenFreeMap Liberty показывает собственные векторные дороги и дорожки. Они не принадлежат импортируемому OSM и продолжали оставаться видимыми даже при переключении графов. После импорта мы скрываем фоновую геометрию транспорта во всех режимах, оставляя прочую картографическую подложку, здания, подписи и спутниковое изображение. При отсутствии загруженной OSM-сети обычные векторные дороги OpenFreeMap возвращаются.

Дополнительно отключённый граф не только получает layout.visibility = none, но и не передаёт объекты в GeoJSON sources. Это исключает возвращение скрытой сети после перестроения стиля, движения камеры или увеличения масштаба.

Название активного режима теперь отображается непосредственно на панели кнопок. Если оно не меняется при клике, значит браузер показывает старый frontend или обновление не попало в запущенный проект.

Подключаемая фотографическая спутниковая подложка не может скрывать дороги на снимках.

Установка: копия проекта -> распаковать ZIP в корень -> `npm run typecheck` -> `npm run test:topology` -> `npm run dev` -> Ctrl+F5.
