# Дорожные знаки и стоп-линии: привязка к полосам (MVP)

## Инструменты

В режиме 2D выберите «Инфраструктура» в левой панели. Поддерживаются:
светофор, STOP, «Уступи дорогу», переход и ручная стоп-линия.
Ранее использовавшиеся круглые маркеры с текстом заменены пиктограммами.

Выберите знак в режиме V, затем настройте в правой панели:

1. Дорогу/подход, если рядом несколько проезжих частей.
2. Направление действия: по OSM, против OSM или оба.
3. Конкретные полосы галочками — например только 2 и 3.
4. Показ автоматической стоп-линии перед знаком (для светофора и STOP включён по умолчанию).

Знак рисуется на выбранной полосе или между выбранными полосами.
Разметка изображается поперёк **только отмеченных полос**. Направление
обрабатывается относительно OSM way, в том числе при `oneway=-1`.

## Что сохраняется в OSM

- `highway=traffic_signals`, `highway=stop`, `highway=give_way`, `highway=crossing` — стандартные OSM-теги.
- `traffic_signals:direction` / `direction` — направление действия (при наличии).
- Ручная стоп-линия — отдельный OSM way с `road_marking=stop_line` и физическими координатами по выбранным соседним полосам.
- `road_editor:road` — ID OSM way, к которому привязан знак.
- `road_editor:lanes` — физические индексы выбранных полос, считая от 1; это **служебный тег редактора**, не стандартная семантика управления движением в OSM.
- `road_editor:stop_line` — вкл/выкл автоматической **визуальной** стоп-линии.

ВНИМАНИЕ: автоматические линии перед светофором/STOP показываются только
в редакторе. Они **не создают отдельные OSM ways**. Для явной стоп-линии
в OSM используйте инструмент «Стоп-линия». Для непоследовательных полос
создавайте несколько отдельных стоп-линий, так как один OSM way не может
одновременно представлять раздельные участки без ложного соединения.

SUMO и Webots автоматически не интерпретируют `road_editor:*` как управление
полосами. Для этого потребуется отдельный адаптер/конвертация в дорожные
соединения SUMO и соответствующие объекты Webots.

## Проверка

В корне проекта:

```cmd
npm run typecheck
npm run test:topology
npm run dev
```

Исходный файл `edited.osm`, проекты на backend, базы данных, мосты,
геометрия дорог и API авторизации этим обновлением не изменяются.
